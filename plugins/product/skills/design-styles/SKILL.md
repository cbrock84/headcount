# Design styles

Three visual directions, each fully specified. Pick one deliberately; do not blend them.

| Direction | Reads as | Reach for it when |
|---|---|---|
| **Minimalist** | Clean editorial: warm monochrome, typographic contrast, flat bento grids, muted pastels. No gradients, no heavy shadows. | Content is the product. Documentation, writing tools, dashboards where data should dominate. |
| **Industrial / brutalist** | Raw mechanical: rigid grids, extreme type-scale contrast, utilitarian color, Swiss print meets terminal. | The product should feel like a tool, not a toy. Developer and infrastructure surfaces. |
| **High-end agency** | Expensive: considered fonts, generous spacing, layered shadows, structured cards, restrained motion. | Marketing surfaces and anything where perceived quality drives the decision to trust. |

## How to use this

1. **Name the direction first**, and say why it fits this product and audience. If the brief does not
   imply one, ask rather than defaulting.
2. **Read the matching reference in full** before writing any markup — each one carries the exact
   type scale, spacing, palette, and motion rules that make the style read as intentional.
3. **Apply it completely.** These styles fail when half-applied: a brutalist grid with soft shadows
   reads as a mistake, not a hybrid.
4. **Do not change structure to suit the style.** If the layout needs to change, that is a separate
   decision and should be stated as one.
