Using this

Sixteen departments, each an independently installable plugin for Claude Code. Install the ones you need — a smaller set triggers more sharply than all of them at once.

1 · Add the marketplace 
/plugin marketplace add cbrock84/headcount
2 · Install a department 
/plugin install security@headcount

Every card below carries its own install line — click one to copy it.

3 · Ask

Skills load themselves when a request matches. Name one directly — /finance:cost-accounting — when you want a specific lens instead.
